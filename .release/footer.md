## Installation

**HACS → ⋮ → Custom repositories** → `stefgo/ha-statistics-legend-table`, category **Dashboard** →
*Add*, then install "Statistics Table and Legend Card".

Manually: download `statistics-legend-table.js` from the assets below, copy it
to `config/www/community/ha-statistics-legend-table/` and register it as a
dashboard resource of type *JavaScript Module*.

Full documentation is in the [README](https://github.com/stefgo/ha-statistics-legend-table#readme).
